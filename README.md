# Moot Spiral

Moot Spiral is a C program that renders a selection of square images as an infinite Fibonacci spiral. Originally intended to create a hypnotic animation that showcases the profile pictures of Twitter mutuals. It uses the Raylib graphics library.

## Requirements

- C compiler such as GCC
- Raylib graphics library added to compiler

## How to Use

- Place your images inside `moots` directory.
- Run either `build.bat` or `build.sh` according to your operating system.

## Controls

- **ESC**: Exit the application
- **Right Arrow**: Increase zoom speed
- **Left Arrow**: Reduce zoom speed

## Customization

You can modify these parameters in the code:

- `FULLSCREEN`: Set to 1 for full screen view
- `MAX_TEXTURES`: Increase if you have more than 1024 images
